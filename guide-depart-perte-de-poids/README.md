# Guide de départ — perte de poids

Projet Elevate Fitness, tenu à part des quatre projets déjà en cours :

- le portail client
- le site web Elevate Fitness
- le guide de macros et de recettes
- le formulaire d’évaluation client

Ce dossier est le point de départ du guide remis à une personne qui commence une démarche de perte de poids. Le contenu (repères, première semaine, suivi) sera ajouté ici, sans toucher aux autres projets.
